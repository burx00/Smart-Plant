# Smart-Plant | Arduino Embedded Systems Project**

Designed and developed an Arduino-based smart plant monitoring system that measures soil moisture levels and provides real-time feedback through a 0.96" OLED SSD1306 display.

The system uses an analog soil moisture sensor to collect environmental data, processes the readings, and presents plant health information through a custom dashboard interface. The project includes sensor calibration, I2C OLED communication, data visualization, and automated plant status detection.

This project strengthened my knowledge of embedded programming, electronics, hardware integration, and developing practical IoT-inspired solutions.
